# ANTHROPIC 증권신고서 해부

앤트로픽 S-1(2026년 10월 26일 SEC 공개 제출)을 원문 대조로 검증해 "흥미로운 12가지 사실" 인터랙티브 스토리 페이지로 만든 프로젝트다.

- 분류: Prototype (공시 원문을 검증된 스토리 페이지로 바꾸는 파이프라인의 첫 사례). 같은 방식으로 두 번째 S-1을 처리하면 Core Asset(Executive Intelligence 축)으로 올린다.
- 목표 등급: 9.5점 (외부 공유 가능한 문서). 숫자 정확성은 10점 기준으로 관리한다.

## 왜

IPO 공시는 길고(이번 S-1은 텍스트 변환 기준 23,197줄), 언론은 같은 서류에서 서로 다른 숫자를 고른다. 이 페이지는 숫자마다 원문 줄번호를 붙여, 독자가 기사 대신 원문을 확인할 수 있게 한다.

## 어떻게 다시 만드나

```bash
python3 -I tools/verify_quotes.py data/s1.txt data/facts.json
```

```bash
python3 -I tools/build.py && python3 -I tools/number_audit.py && python3 -I tools/claims_ledger.py
```

`build.py`는 템플릿에 쓰인 인용 ID가 사실 DB에 하나라도 없거나, 인용문이 원문에서 발견되지 않으면 멈춘다. 숫자를 바꾸려면 먼저 `data/`의 사실을 고치고 다시 빌드한다. 템플릿에 숫자를 직접 쓰는 경우에도 반드시 옆에 `data-f` 인용 버튼을 단다. 뒤의 두 검사는 미확인 숫자나 근거 없는 문장이 하나라도 있으면 실패한다.

로컬 확인은 `.claude/launch.json`의 `s1-story` 서버(포트 8765, `docs` 폴더)로 연다. 아티팩트 갱신은 `build/artifact.html`을 같은 URL로 발행한다.

## 검증 파이프라인 (재사용 템플릿)

1. 정본 확보: EDGAR에서 S-1 원문을 받아 텍스트로 변환한다. 줄번호가 인용 좌표가 된다.
2. 구간 독해: 본문을 8구간으로 나눠 에이전트가 사실 25~40개씩 뽑는다. 사실마다 원문 그대로의 quote와 줄번호를 단다.
3. 반증 검증: 구간마다 별도 검증자가 숫자, 단위(in millions), 기간 열 순서, 계산을 다시 대조한다. 이번에는 61건을 고쳤다.
4. 언론 조사: tier 1 매체 기사를 모으고, 검증자가 URL·제목·날짜와 보도 숫자를 원문과 맞댄다. 엇갈린 곳은 따로 기록해 페이지의 팩트체크 장면이 됐다.
5. 스토리 설계 → 빈칸 보강 → 최종 구성: 스토리 에이전트가 부족한 사실을 요청하면 추가 독해·검증을 한 번 더 돈다.
6. 기계 대조: 모든 인용문을 원문과 공백 정규화 후 대조한다.
7. 발행 전 감사: 페이지에 실제로 적힌 문장과 차트 데이터를 장별 감사자가 원문과 다시 대조한다. 이번에는 1차 51곳, 2차 4곳, 3차 1곳, 4차 4곳을 고쳤고, 5차(주장 366개)에서 지적 0건으로 끝났다. 지적이 0건이 될 때까지 반복한다.
8. 숫자 전수 대조: `number_audit.py`로 페이지 숫자 216개가 모두 근거와 맞는지 확인한다. 미확인이 하나라도 있으면 실패다.
9. 윤문: korean 스킬 규칙(합쇼체, 주술 호응, 번역투 제거)으로 장별 에이전트가 다듬고, `tools/apply_ko.py`가 인용 순서·숫자 목록·태그 구조가 원본과 같은 조각만 반영한다. 윤문 뒤 감사를 다시 돌려 날짜·한정어가 다른 주어로 옮겨 붙은 곳을 고친다(이번에 6~11차, 마지막 본문 지적 0건). 서랍에 뜨는 진술 윤문본은 `data/ko/facts_display.json`에 있다.
10. 기사 확인: 기사 원문을 직접 열어 제목·날짜·바이라인을 확인한다. 열리지 않는 기사는 싣지 않는다.

## 디자인 평가와 개편 (2026년 10월 27일)

페르소나 6명(정보 구조, 데이터 시각화, 감정·몰입, 휴대폰 독자, 모션, 브랜드)이 캡처 19장으로 평가했다(평균 5.5점, 원문은 `data/design/review.json`). 공통 지적은 11개 장이 같은 틀로 반복된다는 것이었다. 그래서 4막 단색 오프너, 검은 화면 고정 태그라인, 128px 대형 숫자, 압축 근거 버튼과 토글, 장 번호 내비와 레일, 고정 차트 열, 어두운 엔딩과 주황 푸터를 넣었다.

## 12가지 사실 구성 (2026년 10월 27일)

컨설턴트식 MECE로 4부 12개 사실을 세웠다. 부마다 질문 하나에 답한다.

| 부 | 묻는 것 | 사실 |
|---|---|---|
| 1 성장의 속도 | 얼마나 빨리 컸나 | 01 매출, 02 고객, 03 생산성 |
| 2 성장의 비용과 재원 | 무엇을 치르고 어디서 돈을 대나 | 04 손익, 05 컴퓨트, 06 파트너 |
| 3 통제의 구조 | 누가 결정하나 | 07 의결권, 08 이사회, 09 창업자 |
| 4 남은 불확실성 | 아직 정해지지 않은 것은 | 10 정부 분쟁, 11 모델 위험, 12 미공개 숫자 |

언론 보도 대조는 회사에 관한 사실이 아니라서 번호 없는 덧붙임으로 뺐다. 제목 12개는 원문 대조 검증자와 MECE 검토자가 따로 봤고, 지적된 과장(인과 단정, "약"과 "주로" 누락, 같은 서류가 아닌 기사 비교)은 모두 고쳤다. 제목은 데스크톱에서 한 줄, 휴대폰에서는 구절 단위로만 줄을 바꾼다(페이지 끝 스크립트가 넘치면 글자 크기를 줄인다).

## 디자인 3차: 뉴모피즘 대시보드

airoasting.com의 피자 대시보드 문법을 따른다. 면은 볼록 카드, 오목 칸, 알약 버튼 세 가지뿐이고 배경과 카드는 같은 색이다. 차이는 그림자로만 만든다. 강조색은 인디고 #5B62D8 하나이고 차트는 파스텔 6색을 쓴다. 표지와 엔딩, 푸터는 짙은 남색 그라데이션이다. 파트마다 바탕색이 다르다(파랑, 모래, 민트, 라벤더). 그림자 색도 그 바탕에서 뽑는다. 파트 경계에는 그림자가 다 퍼질 만큼 여백을 둔다. 이전 디자인은 `_archive/templates/template.preneu.html`에 있다.

## 동행 캐릭터 (2026년 10월 27일)

표지의 픽셀 캐릭터는 스크롤해도 사라지지 않고 끝까지 독자와 함께 움직인다. 화면 전체를 덮는 고정 캔버스 하나(`#field`)에 그리고, 클릭은 캐릭터 위치를 따라다니는 투명 버튼(`#buddyHit`)이 받는다.

- 표지: 본문 문단 오른쪽에 크게 선다. 휴대폰에서는 배지 위 오른쪽 빈자리에 선다.
- 표지를 벗어날 때: 포물선을 그리며 화면 아래 띠로 뛰어내리고 작아진다.
- 아래 띠: 읽은 비율만큼 왼쪽에서 오른쪽으로 걷는다. 다리는 걸은 거리만큼만 움직이고, 스크롤을 올리면 반대쪽을 본다. 발밑에 옅은 그림자가 있다.
- 새 사실에 들어서면 한 번 뛰어오르고 "사실 NN / 12" 말풍선을 1.7초 띄운다.
- 눈은 걷는 방향이나 가까운 마우스 쪽을 본다. 마우스가 닿으면 몸을 이루는 픽셀이 살짝 흩어졌다 돌아온다.
- 캐릭터를 누르면 목차가 열린다.
- 푸터가 보이면 푸터 오른쪽, 원래 캐릭터 자리로 걸어가 앉는다.
- 움직임 줄이기 설정: 같은 자리에 정지 상태로만 그린다.

코드는 `src/template.html`의 "companion character" 블록이다. 이전 표지 전용 캐릭터는 `_archive/templates/template.precompanion.html`에 남아 있다.

## 부록: 기업가치 비교 (2026년 10월 29일)

`#cval` 섹션은 S-1 밖 숫자로 앤트로픽 예상 기업가치를 한국 GDP, 삼성전자·SK하이닉스 시가총액, OpenAI와 비교한다.

- 출처는 `tools/build.py`의 `EXTERNAL`에 등록한다(news-rt-15t, news-oai-852, news-oai-125, news-imf-2026, news-krx-1028, news-fx-1028, dart-shares, news-hk-skt, news-elec-h, news-khan-h).
- 계산값과 보도 숫자는 `tools/number_audit.py`의 `CALC.update`, `REVIEWED.update`에 계산식과 출처를 적는다.
- 갱신 기준: 공모가가 확정되면 1.5조 달러를 확정값으로 바꾸고, 시가총액은 같은 날 종가 × DART 발행주식 수 ÷ 같은 날 환율로 다시 계산한다.
- 폰트는 Pretendard(SIL OFL 1.1)를 `docs/fonts/PretendardVariable.woff2`로 함께 배포한다. 아티팩트 발행 시 `files`에 같은 경로로 올린다.

## 품질 기준

- 페이지의 모든 숫자에는 원문 줄번호 버튼이 있다. 계산값은 등호 아이콘, S-1 밖 정보는 화살표 아이콘으로 구분한다.
- S-1에 빈칸인 숫자(공모가, 3분기 매출, 총 약정액)는 빈칸으로 보여 준다. 역산한 값은 계산이라고 밝힌다.
- 언론 숫자는 "보도에 따르면"으로만 쓴다.
- (2차까지) 디자인은 elayadesign/ai-design-skills의 landing-page-design Part B(서체 하나, 단계값 간격·크기·모서리, 단색 배경, 히어로 제목에만 그라데이션)와 design-to-motion 웹사이트 규칙(IntersectionObserver 1회 등장, 화면에 있을 때만 도는 반복 모션)을 따른다. 전환형 랜딩페이지 구조(Part A)는 스토리 페이지라 적용하지 않았다.

## 실패 조건과 중단 기준

- 인용 ID 누락이나 원문에 없는 인용문이 하나라도 있으면 빌드가 멈춘다. 우회하지 않는다.
- 정정신고서(S-1/A)가 나오면 숫자가 바뀐다. 새 원문으로 1단계부터 다시 돌리고, 페이지에 기준 서류 날짜를 갱신한다.
